# ATX5Vbooster
An interface board enabling powering 5V heavy 90s/00s PC motherboards with modern ATX power supplies (DCDC conversion from 12V input)
[![Watch the video](https://img.youtube.com/vi/BrJlWmi3LqU/maxresdefault.jpg)](https://www.youtube.com/watch?v=BrJlWmi3LqU)

Snag list:
LEDs too bright - increase resistor values
Fitting into a motherboard might be problematic - consider an ATX extension lead
Thickness of the DCDC converter gets in the way
